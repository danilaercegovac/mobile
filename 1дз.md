## Старт работы, подготовка среды
* Необходимо установить среду разработки на языке SWIFT.
Исследовал предметную область. Обнаружил, что разработка на языке SWIFT на ОС Windows имеет значительные ограничения. Писать и запускать SWIFT код на Windows возможно, для этого существует Swift Toolchain, доступный для 
всех ОС, есть и другие способы, например, использовать Visual Studio Code с расширением Swift for Visual Studio Code. Но я подозреваю, что финальным заданием в рамках курса будет создание полноценного приложения на iPhone,
что требует не только компилятор и редактор, но и Apple SDK, симулятор устройств, инструменты для подписи кода и интеграции с экосистемой (например, SwiftUI Preview). Искать обходные пути унизительно, SWIFT, Apple в целом
- не панацея, имею предпочтение в ОС Windows. Поэтому в рамках курса буду работать с языком программирования Android-приложений - Kotlin.
