## Старт работы, подготовка среды
### Необходимо установить среду разработки на языке SWIFT.
Исследовал предметную область. Обнаружил, что разработка на языке SWIFT на ОС Windows имеет значительные ограничения. Писать и запускать SWIFT код на Windows возможно, для этого существует Swift Toolchain, доступный для всех ОС, есть и другие способы, например, использовать Visual Studio Code с расширением Swift for Visual Studio Code. Но я подозреваю, что финальным заданием в рамках курса будет создание полноценного приложения на iPhone, что требует не только компилятор и редактор, но и Apple SDK, симулятор устройств, инструменты для подписи кода и интеграции с экосистемой (например, SwiftUI Preview). Искать обходные пути унизительно, SWIFT, Apple в целом - не панацея, имею предпочтение в ОС Windows. Поэтому в рамках курса буду работать с языком программирования Android-приложений - Kotlin, у которого нет подобных ограничений.
### Необходимо установить среду разработки на языке Kotlin.
В [руководстве](https://habr.com/ru/companies/otus/articles/994146/?ysclid=mv0yv7uzar292407226) рекомендовали установку IntelliJ IDEA с официального сайта jetbrains, но при попытке установки возвращается ошибка "451 Unavailable For Legal Reasons We are sorry, but we are currently unable to provide our products or services to you due to export control regulations.", что означает блокировку для пользователей с российскими IP-адресами из-за правил экспортного контроля.

В открытых источниках рекомендуют использовать альтернативную рабочую среду OpenIDE, созданная на базе IntelliJ IDEA Community Edition. [Сайт](https://openide.ru/download?ysclid=mv0z4qng4a804310502). Начал установку.

Поставил галку на "Create Desktop Shortcut → OpenIDE Pro", "Update Context Menu → Add “Open Folder as Project”" и "Create Associations" → для .kt, .kts. Остальное не необходимо. (Создаю отдельную папку OpenIDE).

Установил, запустил OpenIDE Pro, но оказалось, что для постоянной работы требуется лицензия, бесплатный период - 60 дней.

Создал новый проект, выбрал Kotlin - создался проект с готовой структурой, папками/файлами.
* src — папка для исходного кода, содержащий файлы .kt. Только файлы из этой папки будут компилироваться и участвовать в автодополнении, рефакторингах и т. п. 
  * Main.kt — файл с кодом. Называть основной файл как Main не есть требование, есть соглашение. Основной файл есть файл, содержащий функцию `fun main()`
* .gitignore — файл для Git: в нём перечислены папки и файлы, которые не нужно отправлять в репозиторий (например, кэши, сборки, настройки под конкретного пользователя)
* .idea — настройки проекта под OpenIDE/IntelliJ. Внутри лежат XML‑файлы с конфигурациями: какие SDK подключены, как настроен стиль кода, какие VCS‑репозитории привязаны и т. п.
* out — результат компиляции (.class, артефакты, временные файлы). Файл .class — это скомпилированный байт‑код, который понимает виртуальная машина Java (JVM).
* .iml — файл модуля проекта. Он описывает, что именно является модулем в терминах IntelliJ‑платформы: какие папки считать исходниками, какие — ресурсами, какие зависимости подключены. То есть OpenIDE Pro написан с помощью IntelliJ‑платформы. IntelliJ‑платформа — это «движок»: набор библиотек и компонентов для работы с кодом (индексация, парсинг, автодополнение, отладка, UI‑компоненты). Это не то, что запускается в Main.kt. Это то, на чём делают IDE.
* .aiforopenide — специфичная для OpenIDE папка (скорее всего, хранит настройки AI‑функций, плагинов или кэши под них)
* External Libraries — виртуальная группа подключённых библиотек (JDK, зависимости из Gradle/Maven, плагины) в дереве проекта
* Scratches and Consoles — виртуальная группа с «черновиками» (scratch‑файлами) и консольными скриптами, которые создаются через File → New → Scratch File. Не привязаны к проекту и хранятся отдельно в профиле пользователя.
