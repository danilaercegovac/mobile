## Задание 5. Целочисленное деление

Создайте два положительных целых числа:

- `totalItems`;
- `boxesCount`.

Значение `totalItems` должно быть больше `boxesCount`.

Например, можно представить, что необходимо равномерно распределить некоторое количество устройств по коробкам.

Вычислите:

1. сколько целых элементов попадёт в каждую коробку;
2. сколько элементов останется после равномерного распределения.

Для решения используйте:

- оператор целочисленного деления `/`;
- оператор остатка от деления `%`.

Выведите сообщение:

```text
При распределении <totalItems> элементов по <boxesCount> коробкам в каждую попадет <result>, останется <remainder>.
```

После этого выведите тот же результат как смешанное число:

```text
<totalItems> / <boxesCount> = <целая часть> <остаток>/<делитель>
```

Например:

```text
17 / 6 = 2 5/6
```

# Часть 4. Вычисления с датой без `Date`

## Задание 6. Сколько времени прошло с указанной даты

Создайте три свойства:

- `startDay`;
- `startMonth`;
- `startYear`.

В качестве исходной даты можно использовать дату вашего рождения либо любую другую памятную дату.

Также создайте:

- `currentDay`;
- `currentMonth`;
- `currentYear`.

Для этого задания используйте фиксированную текущую дату:

```text
17 сентября 2026 года
```

При расчётах принять следующие упрощения:

```text
1 месяц = 30 дней
1 год = 360 дней
1 сутки = 24 часа
1 час = 60 минут
1 минута = 60 секунд
```

Високосные годы учитывать не требуется.

Используя **только арифметические операции**, вычислите:

- количество прошедших лет;
- количество прошедших месяцев;
- количество прошедших дней;
- количество прошедших секунд.

Использовать `Date`, `Calendar`, функции работы с датой и условные операторы в этой части нельзя.

Выведите результат:

```text
С указанной даты прошло: <years> лет, <months> месяцев, <days> дней и <seconds> секунд.
```

# Часть 5. Условные конструкции

## Задание 7. Определение квартала

Используя значение месяца из предыдущего задания, определите квартал года:

- январь — март → I квартал;
- апрель — июнь → II квартал;
- июль — сентябрь → III квартал;
- октябрь — декабрь → IV квартал.

Используйте конструкцию:

```swift

else if
else
```

Программа должна корректно обрабатывать значения, которые не соответствуют номеру месяца.

Например:



Проверка корректности диапазона должна действительно исключать **все значения меньше 1 и больше 12**.

# Часть 8. Логические выражения

## Задание 10. Доступ в лабораторию

Представьте, что приложение определяет, можно ли пользователю войти в учебную лабораторию.

Создайте четыре логические переменные:

```swift
hasStudentID
hasScheduledClass
safetyBriefingPassed
isInstructor
```

Обычный студент может войти только в том случае, если одновременно:

- у него есть студенческий ID;
- на текущее время назначено занятие;
- он прошёл инструктаж по технике безопасности.

Преподаватель (`isInstructor == true`) может войти независимо от наличия занятия и прохождения инструктажа, **но идентификатор должен быть у него в любом случае**.

Создайте одно логическое выражение `canEnterLab`, которое описывает эти правила.

Проверьте выражение минимум на четырёх различных комбинациях значений.

Выведите результат:

```text
Доступ разрешен: true
```

или

```text
Доступ разрешен: false
```

# Дополнительное задание

## Задание 11. Поиск ошибки в условии

Дан фрагмент программы:

```swift
let month = 15

if month < 1 && month > 12 {
    print("Некорректный номер месяца")
} else if month <= 3 {
    print("Первый квартал")
} else if month <= 6 {
    print("Второй квартал")
} else if month <= 9 {
    print("Третий квартал")
} else {
    print("Четвертый квартал")
}
```

Ответьте на вопросы:

1. Почему значение `15` не попадает в ветку с сообщением об ошибке?
2. Какой логический оператор использован неверно?
3. Исправьте условие так, чтобы программа корректно обрабатывала любые значения вне диапазона `1...12`.
4. Проверьте программу минимум на значениях:

```text
-1
1
4
9
12
13
```
